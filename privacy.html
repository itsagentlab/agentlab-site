Privacy Policy

AgentLab — last updated 2026-11-07

Scope

This policy describes how AgentLab ("the application"), a private single-user tool operated by an individual ("the operator"), accesses, uses, stores and shares information obtained from Google APIs.

The application is used by the operator, on the operator's own Google account, on their own files. It is not a public service and has no users other than the operator.

What Google user data is accessed

With the operator's explicit consent, the application may access the following data in the operator's own Google account:

  • Google Drive — file names, folder structure, file metadata and file content of files and folders owned by the operator (specifically, the operator's AgentLab folder and its contents).
  • Google Docs — the content of documents created or managed by the operator.
  • Google Sheets — the content of spreadsheets created or managed by the operator.

How the data is used

The data is used for one purpose only: to operate the operator's own content-production workflow — creating, reading, editing and organising the operator's production files. Specifically, to draft episode scripts, keep research notes, and maintain a production-tracking spreadsheet.

The data is not used to:

  • serve advertising, or build advertising or user profiles;
  • train, fine-tune or otherwise develop machine-learning models;
  • determine creditworthiness, or for lending purposes;
  • be sold or transferred to any third party.

How the data is stored

The application runs on the operator's own server. It stores an OAuth 2.0 refresh token locally on that server so it can reconnect without asking the operator to sign in each time. File content is retrieved from the Google APIs when the workflow needs it; documents are not uploaded to, or copied into, any third-party service or cloud other than Google Drive itself.

No data obtained from Google APIs is shared with, or made accessible to, any third party. There are no analytics, tracking or advertising services embedded in this application.

Retention and deletion

  • Documents, spreadsheets and files created by the application live in the operator's own Google Drive and remain under the operator's control. The operator can delete them at any time.
  • The locally stored OAuth token is retained only while the application is in use. Revoking the application's access from the Google Account permissions page, or deleting the stored token, removes the application's ability to access Google data.
  • Revoking access can be done at any time at myaccount.google.com/permissions.

Google API Services User Data Policy — Limited Use

AgentLab's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Changes to this policy

As a single-user application, this policy is amended whenever the application's data handling changes. The "last updated" date at the top of this page reflects the most recent revision.
