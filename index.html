AgentLab

A private, self-hosted automation tool for one YouTube channel owner.

What this application is

AgentLab is a single-user automation tool that its owner uses to run the production pipeline behind one YouTube channel. It is self-hosted on the owner's own server and is not distributed, published in any app store, or offered as a service to anyone else. There is no public sign-up and no other user accounts.

What it does

AgentLab organises production material inside a single Google Drive folder called AgentLab:

  • Google Drive — stores and organises the owner's production files, including an episodes folder, a research folder, and an operations folder.
  • Google Docs — creates and updates episode scripts and research write-ups.
  • Google Sheets — reads and updates the production tracker used to plan episodes and record costs.

All of the above happens inside the owner's own Google account, on the owner's own files. The application does not access or process anyone else's data.

Why it asks for Google authorisation

The tool connects to the Google Drive, Docs and Sheets APIs through OAuth 2.0 so that the owner can authorise their own account to be used by their own software. The authorisation is granted to the owner only, and can be revoked at any time from the owner's Google Account permissions page.
